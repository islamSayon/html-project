📌 Basic VS Code Shortcuts

কাজ Shortcut
New File Ctrl + N
Save File Ctrl + S
Open File Ctrl + O
Terminal Open Ctrl + `
Command Palette Ctrl + Shift + P
💡 এগুলো VS Code এর সবচেয়ে বেশি ব্যবহৃত shortcut।

⚡ Multiple Cursor Tricks

কাজ Shortcut

💡 একসাথে অনেক জায়গায় edit করতে এই shortcut খুব useful।

🚀 HTML Emmet Shortcuts

VS Code এ Emmet ব্যবহার করে খুব দ্রুত HTML লিখতে পারবা।

Example 1:

লিখো: ul>li*5

তারপর Tab চাপো।

Result:

<ul>
  <li></li>
  <li></li>
  <li></li>
  <li></li>
  <li></li>
</ul>
💡 Emmet শিখলে coding speed কয়েকগুণ বেড়ে যাবে।
